# PenguinX Events — แพลตฟอร์มจัดการงานอีเวนต์ภายในองค์กร

ใช้กับงานของเราเอง: TRC · Restech · Damn Expo · CafCon และงานย่อยอีก 5–6 งาน
ใช้ภายในองค์กรเท่านั้น

ยังไม่ได้เริ่มเขียนโค้ด — `docs/plan.md` คือข้อสรุปจากการสำรวจตลาดและโครงที่ตกลงกันไว้

## สแตกที่จะใช้

ชุดเดียวกับ `jeng-nai-kradaat` ที่ทีมรันอยู่แล้ว ไม่เอาของใหม่มาเพิ่มภาระ

| ส่วน | ใช้ |
|---|---|
| หน้าเว็บ | React + Vite + Tailwind |
| หลังบ้าน | Express + PostgreSQL (pg) + JWT |
| โครงโปรเจกต์ | npm workspaces (monorepo) |
| ออกไฟล์ | exceljs, jspdf |
| อีเมล | resend |
| ขึ้นเซิร์ฟเวอร์ | Heroku |

เหตุผล: ทีมเขียนสแตกนี้อยู่แล้ว มี migration และ seed script เป็นแบบแผนอยู่แล้ว
และเรื่องขึ้นเซิร์ฟเวอร์ไม่ต้องเรียนใหม่ ระบบนี้ต้องมีฐานข้อมูลจริงและผู้ใช้หลายคน
พร้อมกัน จึงทำเป็น static site แบบเว็บอื่นของเราไม่ได้
