# ฝากขึ้นเว็บให้ทีมลองใช้

โฟลเดอร์นี้พร้อมขึ้น Vercel แล้ว มีไฟล์เดียวคือ `public/index.html`

**ในนี้เป็นชุดข้อมูลสมมติ** ชื่อบริษัท ชื่อผู้ติดต่อ เบอร์โทร ชื่อเซลล์
ถูกเปลี่ยนเป็นนามแฝงหมดแล้ว ฟังก์ชันทุกอย่างเหมือนของจริงเป๊ะ
ทีมลองกดได้ทุกปุ่มโดยไม่มีข้อมูลลูกค้าหลุด

## ขั้นตอน

```bash
npm i -g vercel
cd deploy
vercel login          # เปิดเบราว์เซอร์ให้ล็อกอินเอง
vercel --prod
```

ได้ลิงก์มาแล้วส่งให้ทีมได้เลย

## ทำไมยังไม่เอาชุดข้อมูลจริงขึ้น

ไฟล์ที่ build ออกมามีข้อมูลฝังอยู่ในตัวไฟล์ทั้งก้อน ใครเปิด view-source ก็เห็นหมด
หน้าล็อกอินที่อยู่ในหน้าเว็บกันไม่ได้เลย เพราะข้อมูลถูกส่งไปถึงเบราว์เซอร์ก่อนจะถามรหัสแล้ว

ถ้าจะเอาชุดจริงขึ้น มีสองทางที่กันได้จริง

1. **Vercel Pro** เปิด Password Protection ที่ตัวโปรเจกต์ ประตูอยู่ชั้นเซิร์ฟเวอร์
   ไฟล์จะไม่ถูกส่งออกไปเลยถ้ายังไม่ผ่านรหัส ประมาณ 20 USD ต่อเดือน
2. **ต่อกับ API ที่ทำไว้แล้ว** หน้าเว็บไม่ฝังข้อมูล แต่ไปดึงจากเซิร์ฟเวอร์หลังล็อกอิน
   สิทธิ์บังคับที่เซิร์ฟเวอร์ตามบทบาทที่ตั้งไว้ ทางนี้ถูกต้องที่สุดและทำค้างไว้แล้วครึ่งทาง
   เหลือแค่ผูกหน้าเว็บเข้ากับ API และหาที่ฝากฐานข้อมูล

## สร้างไฟล์ใหม่หลังแก้โค้ด

```bash
cd prototypes
python3 build.py          # ได้ dist/index.html (ข้อมูลจริง) กับ dist/demo.html (ข้อมูลสมมติ)
cp dist/demo.html ../deploy/public/index.html
```
