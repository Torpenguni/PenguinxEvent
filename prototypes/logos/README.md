# โลโก้งาน

`build-logos.py` จะหยิบไฟล์ในโฟลเดอร์นี้ที่ตั้งชื่อตาม `id` ของงาน
ย่อเหลือด้านยาวสุด 320 px แล้วฝังเป็น data URI ลงทั้ง platform.html
และ platform-demo.html รับ `.png` `.jpg` `.svg` `.webp`

| งาน | ไฟล์ |
|---|---|
| Restech & Thailand Restaurant Conference (`restech`) | `restech.png` |
| Caf con & Damn Expo (`cafcon`) | `cafcon.png` |

## ที่มาของสองไฟล์นี้

`แบนเนอร์รวมโลโก้-ต้นฉบับ.png` เป็นแบนเนอร์เดียวกว้าง 2862×487
ที่มีโลโก้ 4 อันเรียงกัน หาขอบด้วยความหนาแน่นของหมึกรายคอลัมน์
แล้วตัดออกมาเป็น `_restech-ก่อนครอบขอบ.png` และ `_cafcon-ก่อนครอบขอบ.png`
จากนั้นครอบขอบขาวออกด้วย `trimpng.py` ได้ไฟล์ใช้งานจริง

    python3 trimpng.py <ไฟล์เข้า> <ไฟล์ออก>

`sips -c` เขียนไฟล์เสียเมื่อครอบด้วย offset ติดลบ `trimpng.py`
จึงอ่านพิกเซลเองแล้วเขียน PNG ด้วย zlib ไม่พึ่งไลบรารีนอก

## เปลี่ยนโลโก้

วางไฟล์ใหม่ทับแล้วสั่ง `python3 build-logos.py` ในโฟลเดอร์ที่มี mock_*.txt
หรือกดปุ่ม "เปลี่ยนโลโก้" บนการ์ดในหน้าเลือกงานก็ได้
แต่แบบหลังอยู่แค่ในเบราว์เซอร์รอบนั้น รีเฟรชแล้วหาย
