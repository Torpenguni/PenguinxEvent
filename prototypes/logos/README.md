# โลโก้งาน

วางไฟล์โลโก้ที่นี่ ตั้งชื่อตาม `id` ของงาน แล้วสั่ง build ใหม่
ระบบจะฝังลงไฟล์ทั้ง platform.html และ platform-demo.html ให้ถาวร

| งาน | ตั้งชื่อไฟล์ว่า |
|---|---|
| Restech & Thailand Restaurant Conference | `restech.png` |
| Caf con & Damn Expo | `cafcon.png` |

รับ `.png` `.jpg` `.svg` · พื้นหลังโปร่งใสจะสวยที่สุดเพราะการ์ดมีพื้นขาว
ระบบย่อให้เองเหลือด้านยาวสุด 320 px

ถ้าไม่อยากรอ build เข้าไปกดปุ่ม **ใส่โลโก้งาน** บนการ์ดในหน้าเลือกงานก็ได้
แต่จะอยู่แค่ในเบราว์เซอร์รอบนั้น รีเฟรชแล้วหาย เพราะตัวต้นแบบยังไม่มีที่เก็บไฟล์จริง
