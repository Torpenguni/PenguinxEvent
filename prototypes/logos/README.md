# โลโก้งาน

`build-logos.py` หยิบไฟล์ในโฟลเดอร์นี้ที่ตั้งชื่อตาม `id` ของงาน
ย่อเหลือด้านยาวสุด 320 px แล้วฝังเป็น data URI ลงทั้ง platform.html
และ platform-demo.html รับ `.png` `.jpg` `.svg` `.webp`

| งาน | ไฟล์ | ประกอบจาก |
|---|---|---|
| Restech & Thailand Restaurant Conference (`restech`) | `restech.png` | Restech + TRC |
| Caf con & Damn Expo (`cafcon`) | `cafcon.png` | Caf con + Damn Expo |

## ที่มา

`แบนเนอร์รวมโลโก้-ต้นฉบับ.png` กว้าง 2862×487 มีโลโก้ 4 อันเรียงกัน
ลำดับจากซ้ายคือ **TRC · Damn Expo · Restech · Caf con** ไม่ได้เรียงเป็นคู่ตามงาน
จึงต้องจับคู่ข้ามกัน งานละสองโลโก้

หาขอบแต่ละอันจากช่วงว่างสนิทที่ยาวเกิน 18 px ในโปรไฟล์หมึกรายคอลัมน์
ได้ช่วง x คือ 0–421 · 679–1189 · 1426–2189 · 2425–2832
แล้ว `compose.py` ปรับความสูงทั้งคู่ให้เท่ากันที่ 170 px วางเรียงเว้นช่อง 54 px

    python3 -c "import compose; compose.compose('full.bmp',[(1426,2189),(0,421)],'restech.png')"

ย่อภาพใช้การเฉลี่ยทั้งกล่อง ไม่ใช่หยิบพิกเซลเดียว ขอบตัวอักษรจึงไม่แตก

## หมายเหตุ

ไฟล์ต้นฉบับมีหมึกชิดขอบซ้ายที่ x=0 พอดี ตรวจแล้วว่าตัว T ของ TRC
คานบนสมมาตรกับแกนกลาง แปลว่าโลโก้ไม่ได้ถูกตัด เป็นการครอบภาพชิดพอดีเท่านั้น

`trimpng.py` ใช้ครอบขอบขาวรอบภาพเดี่ยว อ่านพิกเซลเองแล้วเขียน PNG ด้วย zlib
เพราะ `sips -c` เขียนไฟล์เสียเมื่อครอบด้วย offset ติดลบ

## เปลี่ยนโลโก้

วางไฟล์ใหม่ทับแล้วสั่ง `python3 build-logos.py` ในโฟลเดอร์ที่มี mock_*.txt
หรือกดปุ่ม "เปลี่ยนโลโก้" บนการ์ดในหน้าเลือกงาน แต่แบบหลังรีเฟรชแล้วหาย
