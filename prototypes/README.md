# ตัวอย่างที่จับต้องได้

เปิดจากไฟล์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลฝังอยู่ในไฟล์

| ไฟล์ | อะไร |
|---|---|
| `booking-board.html` | ผังเต็ม 181 บูธ กดจองได้ คิวรันเอง Feasibility วิ่งตาม และกั้นสิทธิ์ตามบทบาท |
| `trc-floorplan.html` | ผังโซนอาหาร ตัวแรกที่ทำ อ่านอย่างเดียว |
| `stage-agenda.html` | ตารางเวที 3 เวที 3 วัน 137 ช่วง |

## booking-board.html ทำอะไรได้

เลือกบทบาทที่หัวหน้า แล้วดูว่าเห็นอะไรต่างกัน
เซลล์กดบูธว่างเพื่อจอง เลื่อนสถานะ จอง → มัดจำ → จ่ายครบ
บูธที่มีคนถืออยู่แล้วต่อคิวได้ พอกดยกเลิก คิวถัดไปขึ้นมาถือแทนทันที
ตาราง Feasibility ข้างล่างคำนวณใหม่ทุกครั้งที่กด

## ทำใหม่ยังไง

    python3 scripts/sheet_to_plan.py booking.md > plan.json

แล้วเอา plan.json ไปแทนค่าตัวแปร DATA ในไฟล์ html

## ที่ยังไม่จริง

ไม่บันทึก รีเฟรชแล้วรีเซ็ต · สถานะเริ่มต้นเดาจาก Final กับ ส่งฟอร์มที่ 5
เพราะชีตไม่มีคอลัมน์มัดจำ · ยังคิดที่ราคาตั้ง เพราะชีตผังไม่เก็บราคาต่อดีล
· การกั้นสิทธิ์บนหน้าจอเป็นการสาธิต ของจริงต้องตรวจที่เซิร์ฟเวอร์
