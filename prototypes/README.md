# ตัวอย่างที่จับต้องได้

เปิดจากไฟล์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลฝังอยู่ในไฟล์

| ไฟล์ | อะไร |
|---|---|
| `platform.html` | **แพลตฟอร์มทั้งตัว** ล็อกอิน เมนู แดชบอร์ด และทุกโมดูลรวมกัน |
| `booking-board.html` | ผังบูธเดี่ยว ๆ พร้อม Feasibility ที่วิ่งตาม |
| `stage-agenda.html` | ตารางเวที 3 เวที 3 วัน |
| `trc-floorplan.html` | ผังโซนอาหาร ตัวแรกที่ทำ อ่านอย่างเดียว |

## platform.html

ล็อกอิน แล้วเลือกงานก่อนเข้า จากนั้นเป็น shell เดียวเจ็ดหน้า
สลับงานได้ที่หัวแถบซ้าย หรือกด "← ทุกงาน" เพื่อกลับไปหน้าเลือกงาน
สลับบทบาทได้ที่มุมขวาบน

**งานที่มีข้อมูลจริงสองงาน**

| งาน | บูธ | ที่มา |
|---|---|---|
| Restech & Thailand Restaurant Conference | 181 | ชีตผัง + ลิสต์ลูกค้า + Agenda สามเวที |
| CafCon & Damn Expo | 71 | ชีต Damn Expo Booking แท็บที่ชื่อลูกค้าครบสุด |

CafCon & Damn Expo ยังไม่มีตารางเวที และบูธขึ้นเขียวทั้งหมด
เพราะชีตนั้นเก็บแค่ชื่อผู้เช่า ไม่มีสถานะการชำระเงิน

| หน้า | มีอะไร |
|---|---|
| ภาพรวม | ตัวเลขงาน 181 บูธ ขายไปแล้วเท่าไหร่ และรายการที่ต้องรีบตาม |
| ผังบูธ | ผังเต็ม กดจอง เลื่อนสถานะ ต่อคิว คิวเลื่อนขึ้นเองเมื่อยกเลิก |
| ดีลและลูกค้า | 94 ดีล กรองตามสิทธิ์ เซลล์เห็นเฉพาะของตัวเอง |
| Feasibility | ราคาตั้ง ปิดได้ เงินเข้า ค้างรับ คำนวณจากผังโดยตรง |
| เวที | ไทม์ไลน์ 3 เวที 137 ช่วง |
| ดูแลผู้ออกบูธ | เช็กลิสต์ของที่ต้องเก็บจากลูกค้าแต่ละราย |
| ผู้ใช้และสิทธิ์ | ตารางสิทธิ์ทั้งหมด ตรงกับ `role_permission` ในสคีมา |

**ลองแบบนี้** ล็อกอินเป็นเซลล์ก่อน จะเห็นว่าเมนู Feasibility หายไปเลย
แล้วสลับเป็นบัญชีการเงินที่มุมขวาบน เมนูจะโผล่มา ส่วนปุ่มจองบูธหายไปแทน

## ทำผังใหม่ยังไง

    python3 scripts/sheet_to_plan.py booking.md > plan.json

แล้วเอา plan.json ไปแทนค่าตัวแปรข้อมูลในไฟล์ html

## ที่ยังไม่จริง

- **ไม่บันทึก** รีเฟรชแล้วรีเซ็ต ของจริงเก็บลงฐานข้อมูลพร้อม audit log
- **สถานะเริ่มต้นเดา** จาก Final กับ ส่งฟอร์มที่ 5 เพราะชีตไม่มีคอลัมน์มัดจำ
- **คิดที่ราคาตั้ง** ชีตผังไม่เก็บราคาต่อดีล ของจริงขายต่ำกว่าราคาตั้ง 36% เฉลี่ย
- **สิทธิ์บนหน้าจอเป็นการสาธิต** ของจริงต้องตรวจที่เซิร์ฟเวอร์ทุกครั้งที่เรียกข้อมูล
- **สลับงานที่หัวยังไม่ทำงาน** มีข้อมูลแค่ Restech x TRC 2026 งานเดียว
