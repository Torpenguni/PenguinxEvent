# ตัวอย่างที่จับต้องได้

## trc-floorplan.html

ผังบูธโซนอาหารของ Restech x TRC 2026 อ่านอย่างเดียว เปิดจากไฟล์ได้เลย
ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลฝังอยู่ในไฟล์

พิกัดบูธทั้ง 46 ช่องมาจากชีต Booking ของจริง สกัดด้วย `scripts/sheet_to_plan.py`
ไม่ได้วาดใหม่

**สิ่งที่หน้านี้ยังเดา** ชีตผังไม่มีคอลัมน์สถานะ เพราะทีมเก็บสถานะเป็นสีพื้นเซลล์
ซึ่งหายไปตอน export สคริปต์เลยเดาว่าบูธที่มีชื่อผู้เช่าคือขายแล้ว
บูธที่เขียนแค่รหัสคือว่าง ต้องให้ทีมยืนยันก่อนใช้จริง

**ราคาที่ขายได้จริงรู้แค่ 6 จาก 46 บูธ** เพราะชีตงบกับชีตผังไม่ได้ผูกกัน
ต้องไล่จับคู่ทีละรหัสด้วยมือ นี่คือช่องว่างที่ตาราง `deal` ปิดให้

## ทำใหม่ยังไง

    python3 scripts/sheet_to_plan.py booking.md > plan.json

แล้วเอา plan.json ไปแทนค่าตัวแปร DATA ในไฟล์ html
