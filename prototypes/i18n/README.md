# แปลหน้าจอเป็นภาษาอังกฤษ

หน้าจอทั้งหมดแปลเป็นอังกฤษแล้ว ไฟล์ในโฟลเดอร์นี้คือเครื่องมือที่ใช้แปล
เก็บไว้เผื่อต้องแปลรอบใหม่หรือทำสวิตช์สลับภาษาทีหลัง

| ไฟล์ | ทำอะไร |
|---|---|
| `scanjs.py` | เดินทีละตัวอักษรเพื่อแยกว่าข้อความอยู่ในสตริงจริง หรืออยู่ในคอมเมนต์ |
| `phrases.py` | ดึงวลีไทยออกจากสตริง โดยไม่แตะแท็ก HTML |
| `phr_frozen.json` | รายการวลีไทย 986 วลี เรียงตามความถี่ ห้ามสร้างใหม่ ลำดับต้องคงที่ |
| `tr1–tr4.py` | คำแปล อ้างด้วยเลขลำดับใน `phr_frozen.json` |

## ทำไมอ้างด้วยเลขลำดับ

เพราะไม่ต้องพิมพ์ไทยซ้ำ และเลี่ยงปัญหาอักขระหลุดตอนแทนค่า
แต่แลกมาด้วยข้อบังคับว่า **ห้ามสร้าง `phr_frozen.json` ใหม่**
ถ้าสร้างใหม่แล้วจำนวนหรือความถี่เปลี่ยน ลำดับจะเลื่อนและคำแปลจะสลับกันทั้งชุด

## กับดักที่เจอมาแล้ว

- อะพอสทรอฟีในคำแปล เช่น `Other reps' deals` ไปปิดสตริง JS ที่ครอบด้วย `'`
  ตอนแทนค่าจึงแปลง `'` เป็น `’` และ `"` เป็น `”` ทุกครั้ง
- คำที่ใช้ต่อท้ายตัวเลขต้องเป็นพหูพจน์ แต่คำเดียวกันที่เป็นหัวตารางต้องขึ้นต้นตัวใหญ่
  แก้แยกทีหลังด้วยการเทียบบริบท `>คำ</th>` กับ `+' คำ'`

## ที่ยังเป็นภาษาไทย

คอมเมนต์ในโค้ดและ CSS ยังเป็นไทยทั้งหมด เป็นบันทึกสำหรับทีมพัฒนา
ไม่ได้แสดงบนหน้าจอ ถ้าต้องการให้แปลด้วยบอกได้

ข้อมูลใน `app4.json` ซึ่งเป็นไฟล์งานจริง ยังเป็นไทยตามชีตต้นทาง
แปลเฉพาะ `demo.json` ที่เอาไว้ส่งให้คนนอกดู
