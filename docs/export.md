# ส่งออกข้อมูล

แท็บ **ตั้งค่า → ส่งออกข้อมูล** ดาวน์โหลดได้ทุกตารางในระบบ

| ชุดข้อมูล | โมดูลที่ต้องมีสิทธิ์ | มีอะไรอยู่ในไฟล์ |
|---|---|---|
| บูธและผัง | `floorplan` | รหัส โซน พิกัดบนผัง สถานะ ลูกค้า ราคาตั้ง |
| ดีลและลูกค้า | `deal` | ขั้นตอน มูลค่า เซลล์ นัดถัดไป บูธที่ถือ |
| งบประมาณ P&L | `budget` | ทุกบรรทัดของผังบัญชี งบที่ตั้งไว้ ใช้จริง ผลต่าง |
| ตารางเวที | `stage` | ทุกช่วงทุกเวที แยกวันเวลา สถานะยืนยัน |
| สปีกเกอร์ | `stage` | ชื่อ ตำแหน่ง สถานะตอบรับ ช่องทางติดต่อ |
| ไทม์ไลน์โครงการ | `timeline` | ทั้งสามช่วง แผนเทียบกับที่ทำจริง |
| งานที่ผู้ออกบูธต้องส่ง | `exhibitor` | ตารางไขว้ ลูกค้า × รายการงาน |
| แพ็กเกจและราคา | `price` | ราคาตั้ง เงื่อนไข รายการเสริม |
| ทีมขาย | `deal` | ชื่อ อัตราคอมมิชชัน จำนวนดีล มูลค่ารวม |

ชุดที่บทบาทนั้นไม่มีสิทธิ์ดูจะไม่ขึ้นในรายการ และหน้าจะบอกว่าซ่อนไว้กี่ชุด
เช่นบทบาทเซลล์เห็น 8 ชุด ไม่เห็นงบประมาณ

## รวมทีเดียว

- **CSV เดียว** วางทุกตารางต่อกัน คั่นด้วยบรรทัด `### ชื่อตาราง (n แถว)`
  เหมาะกับส่งต่อหรือเปิดดู แต่ต้องแยกตารางเองตอนเอาไปใช้
- **JSON สำรองทั้งงาน** เก็บครบทุกฟิลด์ รวมพิกัดบูธและประวัติการติดต่อ
  ที่ CSV เก็บไม่ได้ ตัดโลโก้กับไฟล์ผังออกเพราะเป็น data URI ก้อนใหญ่

ทุกไฟล์ CSV ใส่ BOM ไว้แล้ว เปิดใน Excel ภาษาไทยไม่เพี้ยน
บนหน้าที่เผยแพร่ใช้ `claude.use("downloads")` ผู้ดูกดยืนยันเองทุกครั้ง
ถ้ารันบนเซิร์ฟเวอร์ของเราเองจะใช้ Blob URL แทน

## รายชื่อเวทีย้ายมาอยู่ในข้อมูลแล้ว

เดิม `SG` ฝังชื่อเวทีสามอันไว้ในโค้ด ตอนนี้อ่านจาก `EV.stages`
และเติมจากเวทีที่พบในตารางเวทีอัตโนมัติ งานใหม่จึงไม่ต้องแก้โค้ด
