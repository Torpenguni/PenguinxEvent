# สองโดเมน หนึ่งฐานข้อมูล

| โดเมน | ใคร | `PXE_APP` | mount อะไร |
|---|---|---|---|
| `event.penguinx.co` | ทีมข้างใน | ไม่ตั้ง | `/api/auth` `/api/events` `/api/booths` `/api/deals` `/api/exhibitor-access` |
| `exhibitor.penguinx.co` | ผู้ออกบูธ | `portal` | `/api/portal` เท่านั้น |

ทั้งคู่ใช้โค้ดชุดเดียวกันและฐานข้อมูล Neon ก้อนเดียวกัน ต่างกันที่ตัวแปรตัวเดียว

การแยกอยู่ที่ชั้น mount ใน `apps/api/src/index.js` ไม่ใช่การเช็กสิทธิ์รายเส้น
โดเมนผู้ออกบูธจึงตอบ 404 กับ `/api/deals` `/api/events` `/api/auth/login` เพราะเส้นทางพวกนั้น
ไม่ได้ถูกโหลดขึ้นมาเลย ไม่ใช่เพราะถูกปฏิเสธสิทธิ์ ลืมเช็กจุดใดจุดหนึ่งก็ยังไม่หลุด

## DNS ที่ Cloudflare

`penguinx.co` ใช้เนมเซิร์ฟเวอร์ของ Cloudflare อยู่แล้ว เพิ่มสองแถว

```
CNAME   event       cname.vercel-dns.com   Proxy: DNS only
CNAME   exhibitor   cname.vercel-dns.com   Proxy: DNS only
```

**ต้องเป็นเมฆสีเทา** ถ้าเปิดพร็อกซีสีส้ม Vercel จะออกใบรับรอง SSL ไม่ได้

## Vercel

สองโปรเจกต์ ทั้งคู่ root directory `apps/api`

โปรเจกต์ทีมข้างใน
```
DATABASE_URL   = สตริง Neon แบบ pooled
JWT_SECRET     = ค่าเดียวกันทั้งสองโปรเจกต์ ไม่งั้น token ข้ามโดเมนไม่ได้
WEB_ORIGIN     = https://event.penguinx.co
PORTAL_URL     = https://exhibitor.penguinx.co
NODE_ENV       = production
```

โปรเจกต์ผู้ออกบูธ เพิ่ม `PXE_APP=portal` และ `WEB_ORIGIN=https://exhibitor.penguinx.co`
ไม่ต้องใส่ `PORTAL_URL`

`JWT_SECRET` ต้องตรงกันเพราะฝั่งทีมเป็นคนออกลิงก์ ฝั่งพอร์ทัลเป็นคนตรวจ
แต่ token คนละชนิดกัน (`kind: 'portal'`) เอาของพนักงานมาใช้กับพอร์ทัลไม่ได้ และกลับกันก็ไม่ได้

## ทางเข้าของผู้ออกบูธทำงานยังไง

ไม่มีรหัสผ่าน ใช้ลิงก์ที่ทีมงานสร้างให้ทีละบูธ

1. ทีมยิง `POST /api/exhibitor-access/:dealId` พร้อมอีเมลผู้ออกบูธ (ต้องมีสิทธิ์ `exhibitor` ระดับ write)
2. ได้ URL หน้าตา `https://exhibitor.penguinx.co/#<กุญแจ>` **คืนมาครั้งเดียว** ฐานข้อมูลเก็บแค่แฮช
3. ผู้ออกบูธเปิดลิงก์ หน้าเว็บแลกกุญแจเป็น token อายุ 12 ชั่วโมง เก็บใน sessionStorage
4. ถอนสิทธิ์ด้วย `POST /api/exhibitor-access/:id/revoke` มีผลทันทีทุก token ที่ออกไปแล้ว
   เพราะทุกคำขอเช็ก `portal_access` ใหม่เสมอ ไม่ได้เชื่อ token อย่างเดียว

กุญแจอยู่หลัง `#` เพราะส่วนนี้เบราว์เซอร์ไม่ส่งไปเซิร์ฟเวอร์ จึงไม่ตกอยู่ใน access log

ยังไม่มีระบบส่งอีเมลอัตโนมัติ ทีมคัดลอกลิงก์ส่งเองก่อน

## ผู้ออกบูธเห็นอะไร

`GET /api/portal/me` คืนเฉพาะของบูธตัวเอง — ชื่อบริษัท รหัสบูธ ขนาด แพ็กเกจ วันเข้าพื้นที่
เช็กลิสต์ 11 งานที่ `task_template.assigned_to = 'exhibitor'` และรายชื่อคนประจำบูธ

ไม่มี endpoint ไหนในพอร์ทัลคืนราคา งบ ดีล หรือผังของคนอื่น

แก้ได้สองอย่าง ติ๊กว่าส่งงานแล้ว กับกรอกรายชื่อคนประจำบูธ ซึ่งบังคับเพดานบัตรตามแพ็กเกจ
(`booth_type.badge_exhibitor` และ `badge_contractor` รวมทุกบูธในดีล) เกินโควตาได้ 409

## ที่ยังไม่ได้ทำ

- ส่งอีเมลเชิญและอีเมลเตือนใกล้ครบกำหนดอัตโนมัติ
- อัปโหลดไฟล์จริง ตอนนี้ติ๊กได้ว่าส่งแล้ว ไฟล์ยังส่งทางอีเมล
- หน้าจอฝั่งทีมสำหรับกดสร้างลิงก์ ตอนนี้มีแต่ API
