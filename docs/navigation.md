# โครงเมนู

## ปัญหาเดิม

เมนูโตขึ้นเรื่อย ๆ จนเป็น 14 อัน และหลายอันเป็นข้อมูลชุดเดียวกันคนละมุม

| ทับกันตรงไหน | เดิม |
|---|---|
| ตารางดีลซ้ำสองที่ | ดีลและลูกค้า · จัดการการขาย |
| ดีลชุดเดิมจัดกลุ่มใหม่ | ผลงานเซลล์ |
| รายได้โผล่สามหน้า | เป้าและ run rate · P&L · รายได้ตามแพ็กเกจ |
| รายจ่ายโผล่สองหน้า | P&L · งบรายจ่าย |
| การตั้งค่าแยกกันอยู่ | แชร์งาน · ผู้ใช้และสิทธิ์ |

## โครงใหม่ 7 เมนู

| เมนู | แท็บ |
|---|---|
| ภาพรวม | — |
| การขาย | บอร์ดท่อการขาย · ดีลทั้งหมด · ผลงานเซลล์ |
| ผังบูธ | ผัง · แพ็กเกจและราคา |
| เงิน | P&L · เป้าและ run rate · รายได้ตามแพ็กเกจ · งบรายจ่าย |
| เวที | — |
| ผู้ออกบูธ | ติดตามงาน · มุมมองผู้ออกบูธ · ตั้งค่ารายการงาน |
| ตั้งค่า | แชร์งาน · ผู้ใช้และสิทธิ์ |

**สิทธิ์อยู่ที่ระดับแท็บ ไม่ใช่ระดับเมนู** เช่นเมนูเงินมีสี่แท็บที่ต้องสิทธิ์ต่างกัน
บทบาทไหนไม่มีสิทธิ์แท็บไหนก็ไม่เห็นแท็บนั้น และถ้าไม่เหลือสักแท็บ เมนูทั้งอันจะหายไป

เซลล์จึงเห็น 5 เมนู ส่วนแอดมินเห็น 7

## ทุกแท็บต้องแก้อะไรได้

รอบนี้เติมส่วนที่เป็นหน้าอ่านอย่างเดียวให้แก้ได้

| แท็บ | แก้อะไรได้ |
|---|---|
| ผลงานเซลล์ | ย้ายดีลให้เซลล์คนอื่น บูธที่ผูกอยู่ย้ายตามทั้งหมด |
| P&L | แก้ตัวเลขตามแผนรายหมวด ต้องเลือกดูทีละงานก่อน |
| ตั้งค่ารายการงาน | เพิ่ม ลบ แก้ชื่องาน กำหนดส่ง และย้ายว่าใครรับผิดชอบ |

แท็บที่แก้ได้อยู่แล้ว — ผัง (จอง เลื่อนสถานะ แก้ราคา แนบโลโก้) · แพ็กเกจและราคา ·
บอร์ด (ลากเปลี่ยนขั้น บันทึกการติดต่อ) · เป้า · งบรายจ่าย (จ่ายจริง ซัพพลายเออร์ แนบไฟล์) ·
เวที (แก้ในตาราง) · ติดตามงาน (ติ๊กงาน) · แชร์งาน · ผู้ใช้และสิทธิ์

**ภาพรวมตั้งใจให้อ่านอย่างเดียว** เป็นหน้าสรุป ไม่ใช่หน้าทำงาน
