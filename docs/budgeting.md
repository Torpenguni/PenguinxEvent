# ทำงบในระบบ

โครงตามชีต Feasibility ที่ทีมใช้อยู่ **หมวดหลัก → หมวดย่อย → รายการ**

## แต่ละรายการ

| ช่อง | ที่มา |
|---|---|
| จำนวน · หน่วย · ราคาต่อหน่วย | ชีตมีสามช่องนี้อยู่แล้ว เช่น 40 ห้อง x 900 บาท |
| ตั้งงบ | คำนวณจาก จำนวน x ราคาต่อหน่วย ถ้าไม่ได้ใส่ก็พิมพ์ยอดรวมตรง ๆ |
| จ่ายจริง | ใส่แล้วสถานะเลื่อนเป็น "จ่ายแล้ว" ให้เอง |
| ต่าง | ตั้งงบ ลบ จ่ายจริง ติดลบขึ้นแดง |
| สถานะ | ตั้งงบไว้ · มีใบเสนอราคา · ตกลงแล้ว · จ่ายแล้ว |
| ซัพพลายเออร์ · เบอร์ | จากคอลัมน์ Supplier ในชีต |
| เอกสาร | แนบใบเสนอราคาเก็บไว้เป็นหลักฐาน |

## แก้โครงได้เอง

เพิ่มหมวดหลัก เพิ่มหมวดย่อย เพิ่มรายการ เปลี่ยนชื่อ และลบได้ทั้งหมด
ยอดรวมของหมวดย่อยและหมวดหลักคำนวณสดทุกครั้ง

**ต่างจากชีตตรงนี้** ในชีตยอดรวมเป็นสูตรที่ต้องลากช่วงเอง
ซึ่งเป็นสาเหตุที่บรรทัด TOTAL SITE OPERATIONS หายไป 3,000,000 พอดีกับค่าสถานที่ IMPACT Hall
ระบบคำนวณจากรายการจริงเสมอ เรื่องนี้จึงเกิดไม่ได้

## แยกสีตามหมวด

แต่ละหมวดหลักมีแถบสีของตัวเองพร้อมยอดสามตัวบนหัวแถบ — ตั้งไว้ · จ่ายจริง · เหลือหรือเกิน
พับเก็บได้ทีละหมวด เพราะ 93 รายการเลื่อนยาวเกินกว่าจะหาเจอ

## เชื่อมกับ P&L

หน้า P&L อ่านยอดรายหมวดจากหน้านี้โดยตรง แก้ที่นี่แล้ว P&L ขยับตาม
ไม่มีการกรอกซ้ำสองที่

## ตัวคูณสองชั้น

ชีตคิดต้นทุนแบบ **จำนวน x จำนวน x ราคาต่อหน่วย** เช่น Intercom 6 ตัว x 3 วัน x 800 = 14,400
ตอนแรกผมเก็บมาแค่ชั้นเดียว ยอดเลยเพี้ยน — Intercom กลายเป็น 4,800 และผลรวมทั้งงาน
บวมจาก 15 ล้านเป็น 12.2 ล้านผิดทิศ

ตอนนี้เก็บครบทั้งสองชั้นตามสคีมา (`fc_qty` `fc_unit` `fc_qty2` `fc_unit2` `fc_unit_cost`)
และมีธง `calc` บอกว่าบรรทัดนั้นคำนวณจากจำนวนได้จริงหรือไม่

**62 จาก 93 บรรทัดคำนวณจากจำนวนได้** ที่เหลืออีก 31 บรรทัดจำนวนเป็นข้อมูลประกอบ
ไม่ใช่ตัวคูณ เช่น "ค่าสถานที่ IMPACT Hall 3 วัน 3,000,000" ที่ 3,000,000 คือยอดรวม ไม่ใช่ราคาต่อวัน
บรรทัดพวกนี้ใช้ยอดที่ชีตเขียนไว้ และพิมพ์ทับได้

ผลรวมตอนนี้ 15,020,800 ตรงกับชีต

# P&L แบบต้นไม้

กดสามเหลี่ยมหน้าแถวเพื่อกางลงทีละชั้น

    รายได้
      └ รายงาน
          └ รายแพ็กเกจ
    รายจ่าย
      └ หมวดหลัก
          └ หมวดย่อย
              └ รายการ   ← แก้ยอดและเพิ่มรายการได้ตรงนี้

มีปุ่มกางทั้งหมด/ยุบทั้งหมด กางเต็มที่ได้ 157 แถว
แถบเล็ก ๆ ข้างชื่อแสดงสัดส่วนที่ใช้ไปเทียบกับที่ตั้งไว้ เกินงบขึ้นแดง

**แก้ได้ในชั้นล่างสุด** เฉพาะตอนเลือกดูทีละงานและมีสิทธิ์ `budget = write`
เพิ่มรายการ เพิ่มหมวดย่อย และเพิ่มหมวดหลักได้จากในต้นไม้เลย

CSV ที่ดาวน์โหลดมีคอลัมน์ชั้นด้วย จะได้เปิดใน Excel แล้วยังรู้ว่าอะไรอยู่ใต้อะไร

## แก้ตัวเลขตรงไหน

แก้ได้สองที่ ใช้คนละจังหวะ

**เมนู เงิน → งบรายจ่าย** สำหรับตอนทำงบ มีครบทุกช่อง
จำนวน หน่วย ตัวคูณชั้นสอง ราคาต่อหน่วย สถานะ ซัพพลายเออร์ เบอร์ และแนบใบเสนอราคา

**เมนู เงิน → P&L** สำหรับตอนดูภาพรวมแล้วอยากแก้เลย
กางถึงชั้นล่างสุดจะเจอช่อง ตามแผน กับ ตอนนี้ แก้ได้ทั้งคู่

ทั้งสองที่เขียนลงข้อมูลชุดเดียวกัน แก้ที่ไหนก็เห็นอีกที่ทันที

**เงื่อนไขที่ต้องครบก่อนถึงจะแก้ได้ใน P&L**

1. เลือก "เฉพาะงานนี้" ไม่ใช่ "ทุกงานรวมกัน" เพราะยอดรวมหลายงานแก้ทีเดียวไม่ได้
2. มีสิทธิ์ `budget = write` คือบัญชีการเงินและแอดมิน
3. กางลงถึงชั้นรายการ หัวหมวดกับหัวหมวดย่อยเป็นผลรวม แก้ตรงนั้นไม่ได้

**ช่องที่แก้ได้มีเส้นประใต้ตัวเลข** และมีคำอธิบายอยู่เหนือตาราง
Enter บันทึก Esc ยกเลิก

**บรรทัดที่คำนวณจากจำนวน** จะมีตัวเลขเล็ก ๆ ต่อท้ายชื่อ เช่น `6×3×800`
พิมพ์ยอดรวมทับได้ ระบบจะเลิกคำนวณจากจำนวนสำหรับบรรทัดนั้น
