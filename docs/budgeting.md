# ทำงบในระบบ

โครงตามชีต Feasibility ที่ทีมใช้อยู่ **หมวดหลัก → หมวดย่อย → รายการ**

## แต่ละรายการ

| ช่อง | ที่มา |
|---|---|
| จำนวน · หน่วย · ราคาต่อหน่วย | ชีตมีสามช่องนี้อยู่แล้ว เช่น 40 ห้อง x 900 บาท |
| ตั้งงบ | คำนวณจาก จำนวน x ราคาต่อหน่วย ถ้าไม่ได้ใส่ก็พิมพ์ยอดรวมตรง ๆ |
| จ่ายจริง | ใส่แล้วสถานะเลื่อนเป็น "จ่ายแล้ว" ให้เอง |
| ต่าง | ตั้งงบ ลบ จ่ายจริง ติดลบขึ้นแดง |
| สถานะ | ตั้งงบไว้ · มีใบเสนอราคา · ตกลงแล้ว · จ่ายแล้ว |
| ซัพพลายเออร์ · เบอร์ | จากคอลัมน์ Supplier ในชีต |
| เอกสาร | แนบใบเสนอราคาเก็บไว้เป็นหลักฐาน |

## แก้โครงได้เอง

เพิ่มหมวดหลัก เพิ่มหมวดย่อย เพิ่มรายการ เปลี่ยนชื่อ และลบได้ทั้งหมด
ยอดรวมของหมวดย่อยและหมวดหลักคำนวณสดทุกครั้ง

**ต่างจากชีตตรงนี้** ในชีตยอดรวมเป็นสูตรที่ต้องลากช่วงเอง
ซึ่งเป็นสาเหตุที่บรรทัด TOTAL SITE OPERATIONS หายไป 3,000,000 พอดีกับค่าสถานที่ IMPACT Hall
ระบบคำนวณจากรายการจริงเสมอ เรื่องนี้จึงเกิดไม่ได้

## แยกสีตามหมวด

แต่ละหมวดหลักมีแถบสีของตัวเองพร้อมยอดสามตัวบนหัวแถบ — ตั้งไว้ · จ่ายจริง · เหลือหรือเกิน
พับเก็บได้ทีละหมวด เพราะ 93 รายการเลื่อนยาวเกินกว่าจะหาเจอ

## เชื่อมกับ P&L

หน้า P&L อ่านยอดรายหมวดจากหน้านี้โดยตรง แก้ที่นี่แล้ว P&L ขยับตาม
ไม่มีการกรอกซ้ำสองที่
