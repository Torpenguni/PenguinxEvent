# ไฟล์ผังพื้นที่

แถบอัปโหลดอยู่บนสุดของหน้าผังบูธ เห็นทุกบทบาท แต่ปุ่มอัปโหลดขึ้นเฉพาะ
บทบาทที่แก้ผังได้ (`floorplan` = write)

## รับไฟล์อะไรบ้าง

| ชนิด | นามสกุล | ทำอะไรได้ |
|---|---|---|
| ไฟล์ภาพ | png jpg jpeg webp svg | วางเป็นพื้นหลังใต้ผังบูธได้ ปรับความเข้มและขนาดได้ |
| PDF | pdf | เก็บไว้ให้ทีมเปิดและโหลด |
| CAD | dwg dxf | เก็บไว้ให้ทีมเปิดและโหลด |

เบราว์เซอร์วาด DWG/DXF เองไม่ได้ และ PDF วาดเป็นพื้นหลังไม่ได้โดยไม่พึ่งไลบรารีภายนอก
ซึ่งติดนโยบายความปลอดภัยของหน้าที่เผยแพร่ ทั้งสองชนิดจึงเก็บไว้เป็นไฟล์แนบ
พร้อมบอกวิธีทำให้ใช้เป็นพื้นหลังได้ — export เป็น PNG แล้วอัปทับ

## พื้นหลังผัง

ไฟล์ภาพจะถูกวางเป็นชั้นใต้ SVG ผังบูธ (`#planbg`) เพื่อให้วางบูธทับแบบจริงได้

- **แสดงเป็นพื้นหลัง** เปิดปิดได้ ปิดแล้วไฟล์ยังอยู่
- **ความเข้ม** 5–100% ค่าเริ่มต้น 45% พอให้เห็นเส้นผังแต่ไม่กลบบูธ
- **ขนาด** 30–300% ไว้ปรับให้สเกลของผังตรงกับตารางบูธ

สองอย่างหลังปรับแล้วเห็นผลทันทีโดยไม่วาดผังใหม่ทั้งอัน

## ข้อจำกัด

- ไฟล์ต้องไม่เกิน 12 MB ไฟล์ภาพถูกย่อเหลือด้านยาวสุด 2400 px ก่อนเก็บ
- เก็บเป็น data URI อยู่ในตัวงาน ยังไม่ได้ต่อกับที่เก็บไฟล์จริง
  ของจริงควรอัปขึ้น object storage แล้วเก็บแต่ URL
